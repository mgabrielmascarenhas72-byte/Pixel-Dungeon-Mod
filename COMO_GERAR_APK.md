# Pixel Dungeon modificado — compilação pelo GitHub

Este projeto foi preparado para ser compilado pelo GitHub Actions.

1. Crie um repositório no GitHub.
2. Envie **todo o conteúdo desta pasta** para o repositório (não envie a pasta externa que contém este arquivo).
3. Abra a aba **Actions**.
4. Escolha **Build Pixel Dungeon APK**.
5. Toque em **Run workflow**.
6. Quando terminar, abra a execução concluída e procure **Artifacts**.
7. Baixe `Pixel-Dungeon-modificado`.

O workflow baixa automaticamente a biblioteca PD-classes necessária durante a compilação.
